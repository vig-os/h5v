# [PR 13](https://github.com/vig-os/h5v/pull/13) chore(deps): enable the Renovate cargo manager

## Description

Enable Renovate's `cargo` manager so Renovate opens update and vulnerability PRs for the Rust dependencies. The org is moving vulnerability-fix PRs from Dependabot security updates to Renovate (vig-os/org-config#307), and Renovate only opens a vulnerability PR for a dependency that an enabled manager extracts.

## Type of Change

- [x] `chore` -- Maintenance task (deps, config, etc.)

## Changes Made

- `renovate.json`: `enabledManagers` goes from `["github-actions", "pep621", "npm"]` to `["github-actions", "cargo"]`. The repo has no `pyproject.toml` or `package.json`, so `pep621` and `npm` matched nothing.
- `CHANGELOG.md`: entry under `## Unreleased` / `### Changed`.

The shared preset already turns on weekly `lockFileMaintenance`, so with `cargo` enabled Renovate also regenerates `Cargo.lock`. That makes the open Dependabot PR #11 (rand 0.8.5 -> 0.8.8) obsolete once the first lock file maintenance run lands. This PR leaves #11 open.

## Changelog Entry

### Changed

- **Renovate manages the Rust dependencies** ([#12](https://github.com/vig-os/h5v/issues/12))
  - `renovate.json` enables the `cargo` manager, so Renovate opens update and
    vulnerability PRs for `Cargo.toml`, and its weekly lock file maintenance
    regenerates `Cargo.lock`.
  - Drops the `pep621` and `npm` managers: the repo has no `pyproject.toml` or
    `package.json` for them to read.
